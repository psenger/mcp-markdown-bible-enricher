# Product Roadmap

## Phase 1: MVP

- Bible Gateway hyperlinks for all Scripture references (chapter:verse, verse ranges, multi-verse groups)
- Obsidian wiki-links (`[[Book-NN#vN]]`) for cross-referencing within an Obsidian vault
- Catechism of the Catholic Church (CCC) reference links
- All 73 books of the Catholic Bible, including 7 deuterocanonical books
- Bare chapter references (e.g. `Isaiah 53`) and single-chapter book bare verses (e.g. `Jude 9`)
- YAML frontmatter protection — enrichment skips the frontmatter block
- Configurable Bible translation via `BIBLE_VERSION` env var (default: NRSVCE)
- Optional Obsidian link output via `INCLUDE_OBSIDIAN_LINKS` env var
- MCP tools: `bible_enrich_markdown` (string in / string out) and `bible_enrich_file` (file path in / file out)
